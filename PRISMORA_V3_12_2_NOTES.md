# Prismora 3.12.2

- Repeat is directly visible on the Player screen.
- Player now contains Shuffle, Repeat, Sleep and a Playback panel.
- Playback panel mirrors Settings / Playback: repeat modes, shuffle, direct sleep durations, queue persistence, queue/reorder and gapless status.
- Queue order can be changed with up/down buttons and optionally restored after app restart.
- Shuffle is now persisted as a playback preference.
- Development Pro gate: pressing OK grants development access and runs the requested action immediately. Future Pro gates are bypassed until RESET DEV ACCESS is used.
- Real Google Play billing is still absent.
- Features whose underlying engine is not implemented yet remain pending; they are not falsely simulated.

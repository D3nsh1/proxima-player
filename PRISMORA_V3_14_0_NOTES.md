# Prismora v3.14.0 — Cassette hardware + light flat themes

## Cassette theme
- Reworked Player screen into a Sony-inspired blue personal-stereo / cassette-hardware layout based on the supplied mockup.
- Album art is now a small hardware insert instead of the normal giant glass artwork.
- Tape reels visibly change with playback progress.
- The cassette itself acts as the progress visualization; the normal seek slider is not shown in this layout.
- Next/skip button behavior:
  - tap = next track
  - hold (~320 ms) = fast-forward current track
  - fast-forward advances while held and seeks to the previewed position on release
- Added explicit HOLD NEXT = FAST FORWARD hint.

## New brighter non-liquid-glass themes
- Paper White — flat warm-paper UI with blue/red print accents.
- Sakura Pop — bright pink/white solid-panel player.
- Bauhaus Player — cream/red/blue geometric hi-fi layout.
- BRUTAL // RAW — high-contrast neo-brutalist white/black/blue/red blocks.

These new themes use opaque/flat colors and dedicated backdrops instead of the liquid-glass glow background.
